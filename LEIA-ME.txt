NOVO POKE IDLE
==============

Jogo web (React + Vite) com backend no Supabase. A RAIZ do repositorio E o app —
`src/`, `index.html` e `package.json` ficam aqui, sem pasta `web/`. Isso existe
pra o Cloudflare Pages funcionar sem configurar "root directory".

RODAR LOCAL
  npm install
  npm run dev            -> http://localhost:5173

  Precisa de .env.local com VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY e
  VITE_SERVIDOR_URL (ver .env.example). A ultima e OBRIGATORIA: quem grava o
  progresso e o servidor, e a RLS recusa escrita vinda do navegador.

PUBLICAR
  Site      -> Cloudflare Pages, automatico pelo push na main.
               build `npm run build`, saida `dist`, root padrao (a raiz).
  Servidor  -> npm run edge:publicar     (Supabase Edge Function `jogo`)
  Banco     -> npx supabase db push

O QUE MORA ONDE
  src/         o jogo (React + motor)
  assets/      arte (281MB) — copiada pra dist/ no build
  server/      o servico de autoridade; roda local (node) ou como Edge Function
  supabase/    migrations + a Edge Function publicada
  scripts/     pipeline de dados (catalogo, sprites, tiers de spawn) — CommonJS,
               por isso tem um package.json proprio marcando "type": "commonjs"

DADOS DO JOGO
  npm run catalog:gerar       regenera o catalogo a partir do Postgres
  npm run catalog:verificar   prova que o Postgres reproduz a planilha

O JOGO VANILLA ANTIGO
  Saiu deste repositorio (esta em "NOVO POKE IDLE - vanilla" na Area de
  Trabalho). Enquanto ficava aqui, era publicado por acidente sempre que o
  deploy apontasse pra raiz — foi o que aconteceu no Cloudflare Pages.
