NOVO POKE IDLE
==============

Jogo web (React + Vite) com backend no Supabase.

RODAR LOCAL
  npm run dev          -> http://localhost:5173

  Precisa de web/.env.local com VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY e
  VITE_SERVIDOR_URL (veja web/.env.example). A ultima e OBRIGATORIA: o servidor
  e quem grava o progresso, e a RLS recusa escrita vinda do navegador.

PUBLICAR
  Site      -> Cloudflare Pages, automatico pelo push na main.
               Config: root `web`, build `npm run build`, saida `dist`.
  Servidor  -> npm run edge:publicar   (Supabase Edge Function `jogo`)
  Banco     -> npx supabase db push

DADOS DO JOGO
  npm run catalog:gerar       regenera o catalogo a partir do Postgres
  npm run catalog:verificar   prova que o Postgres reproduz a planilha

O JOGO VANILLA ANTIGO
  Saiu deste repositorio (esta em "NOVO POKE IDLE - vanilla" na Area de
  Trabalho). Ele nao usava login nem servidor: salvava em localStorage. Enquanto
  ficava aqui, era publicado por acidente sempre que o deploy apontava pra raiz
  do repositorio — foi exatamente o que aconteceu no Cloudflare Pages.
